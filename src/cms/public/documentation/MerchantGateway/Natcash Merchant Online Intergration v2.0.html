1.      Initiating a Payment Transaction

Step 1: The third-party system calls the Backend to generate a WebView URL for a new transaction. The third party must include the following fields in the request body:

Domain UAT: https://testmerchantpay.natcom.com.ht/api

API:

-          /online-payment/credential

-          Method: POST

 

Schema

{

    "requestId": "2fd4dc38-2a5b-411c-9933-c5e4feb404ff",

Step 2: After receiving the webview url of the transaction, the third-party system redirects to the webview.

 

Step 3: The customer completes the transaction, and the transaction result is sent back to the third party via the Callback URL with the following parameters:

 

Name

Type

Description

code

String

 

The response code of the transaction (Detailed descriptions are provided in the table below)

transId

String

Natcash system transaction ID (in case the transaction is successful)

orderNumber

String

Partner’s order number

signature

String

Data signature

 

 

Code

Mô tả

1

Successful transaction

-3

Unknow status

-1

Transaction failed

 

 

Step 4: After receiving the transaction result from the callbackUrl, the third party verifies the signature to authenticate the received result.

 

The signature is created by HMAC-SHA256

with funcation_code for this JSON with format:

“accessKey + orderNumber + code”

 

accessKey = SHA256(function_code +orderNumber),

function_code will be provided by Natcash: FUNCTION_CODE

 

Step 5: If the signature is verified successfully, the partner system receives the transaction response from the callback URL to continue the process

 

2.      Transaction result query API

This API allows the integrated party to query the transaction result. It is used when the integrated party receives the transaction result from the callbackUrl and needs to verify the received transaction result or used in cases where the transaction result was not received (code = “-3”).

 

Domain UAT: https://uateuapi.natcom.com.ht

API:

-          /online-payment/merchant/checkTransaction

-          Method: POST

 

 

Schema

{

    "username": "USERNAME",

    "password": "PASSWORD",

    "partnerCode": "PARTNER_CODE",

    "orderNumber":"NKUF92746454864425344",

   "signature": "dc49a110ae155df646444ec29eb186028e7ade759ca9bd4ea03aec8536b0d4bb"

 

}

String (Require)

250

Password provided to the third party.

orderNumber

String (Require)

50

Order number from the third party

partnerCode

String (Require)

250

Partner code provided to the third party.

signature

String (Require)

50

signature must be sent with all client requests. The signature is created by HMAC-SHA256

with private_key for this JSON with format:

“accessKey + partnerCode + username + password + orderNumber + requestId”

3.      Cancel transaction API

When the partner fails to credit the customer's account, this API is called to refund the amount back to the customer's Natcash wallet

*Note: A transaction can only be canceled within 30 minutes after the partner receives the result from the callback URL.
